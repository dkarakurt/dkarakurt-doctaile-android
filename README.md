# doctaile

Elindeki malzemelerle yapılabilecek kokteylleri bulan Android uygulaması. Telefonlarda tek sütun düzeninde açılır; Galaxy Z Fold 8'de kitap modunda sol sayfa malzemeleri, sağ sayfa hazırlanışı gösterir.

## APK'yı indirmek
Bu depoya her push yapıldığında GitHub Actions APK'yı otomatik derler. En son derlenen APK, sağdaki **Releases** bölümünde `doctaile.apk` adıyla durur.

## Kurulum
1. `doctaile.apk` dosyasını telefona indir.
2. Dosyaya dokun ve gerekirse "Bilinmeyen uygulamaları yükle" iznini ver.
3. Play Protect uyarı verirse **Yine de yükle** seç.

Uygulama arayüzünün tamamı `app/src/main/assets/index.html` dosyasında.
